# BTSB Bench Test — Pre-Registration

Pre-registered protocol and apparatus verification records for
**CIP-BTSB-BT-001**, a bench-scale test of the phase-change buffering
mechanism used in the BTSB inter-cell safety pad.

Committed **25 August 2026 — before any heat was applied to the test
fixture.** Predictions, analysis method and falsification criteria are
fixed in Rev A and are not revised after the data are seen.

## Contents

| File | Contents |
|---|---|
| `BTSB_Test_Report_RevA_PreRegistration.pdf` | Protocol, predictions, pre-specified analysis, falsification criteria |
| `BTSB_Gate1_Software_Chain_Record.pdf` | Logging chain verification; sampling interval measured at 1.003 s |
| `BTSB_Gate2_Sensing_Record.pdf` | Thermocouple verification incl. boiling-water span check |
| `BTSB_Gate3_Heater_Circuit_Record.pdf` | Heater circuit, series topology, delivered power 14.2 W measured |

## What this test does not do

It tests two constituent mechanisms of BTSB in isolation, using proxy
materials, in a fixture that is not a battery pack. No lithium-ion cell
is present. No thermal runaway is initiated. Section 2 of the report
states the limits in full.
